# Token-budget NAR batching: functional control, no demonstrated E2E gain

## Setup

2026-10-09, H800, MPS off. FIFO admission combines batch count with maximum-chunk cost `prefix_length + 2 * chunk_frames + 3`; oversized single requests run alone. Compare previous B2 queue, max B4/token 32768 and max B4/token 49152, in that order; each 64 prompts/two full warmups. AR32/KV24 GiB/client 64/window 200 ms/VAE1/fullCoT/CFG1/ABC 4096/semantic 9000, highest priority/MAX_INFLIGHT2. Low-frequency job/pump probes remain.

## Results

| Metric | Previous B2 | B4 cap/32768 tokens | B4 cap/49152 tokens |
| --- | ---: | ---: | ---: |
| Audio/s | 21.91625 | 21.96552 | 21.67966 |
| Content TPS | 745.59 | 747.15 | 737.20 |
| E2EL P50/P95 (s) | 354.511/610.896 | 346.646/597.392 | 369.001/613.979 |
| RTF P50/P95 | 1.46324/2.44901 | 1.45053/2.43325 | 1.43989/2.47410 |
| Device peak (GiB) | 71.798 | 58.516 | 57.061 |
| Allocated/reserved peak (GiB) | 38.739/70.609 | 37.627/57.330 | 40.019/55.871 |
| Actual jobs | 36 B1+14 B2 | 46 B1+9 B2 | 38 B1+10 B2+2 B3 |

Throughput changes +0.225%/−1.080%; no long-song B4 formed. All 192 timed/six warmup outputs passed, with zero retries/OOM and empty final states. Lower observed device peaks primarily reflect reserved memory; they are not universal capacity guarantees.

48 CPU tests passed. Fixed-input checks covered 48 songs with real B2/B3/B4; mixed/long outputs were exact to B1. Two short packed outputs differed from B1 (relative L2 0.014127/0.019728). Twenty follow-up outputs reproduced B1 and showed B4 equal to B2 for the tested short set. Eight short E2E requests formed two B4 jobs. Defaults remained B1/budget 0.

A later direct-main comparison was 21.815→21.907 audio-s/s (+0.419%), TPS 741.92→745.15, device peak 54.421→58.516 GiB. The approximately 13 GiB saving above is versus the previous B2 queue, not native main.

## Scope

The budget limits packed token volume; compute cost and peak memory still depend on shape. Three sequential instrumented calibrations produced small differences. Short-input packed numerical differences and WSB/CFG≠1 quality remained open; deployment comparisons require tuning both sides.
