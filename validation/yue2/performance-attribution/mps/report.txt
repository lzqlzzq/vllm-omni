# 新 H800：同候选 MPS 开关交错验证

四轮完成。当前同进程分阶段队列候选开启 MPS **没有观察到收益**：两组配对吞吐分别 −0.69% / −1.51%，E2EL P95 分别 +1.29% / +0.54%。RTF P95 一升一降。新卡全程没有采到温控降频标志，因此本轮不能再用旧卡热限制解释结果。

这支持降低“可由 MPS 缓解的跨进程 CUDA context switching 是当前主要瓶颈”的优先级。不能由此证明所有 GPU 调度、资源竞争、stream 优先级、同步或 CPU 线程切换成本为零；本轮没有阶段探针，也没有隔离这些机制。当前候选本来就在同 worker/context 内执行，MPS 开关是诊断证据，不是所有切换成本的直接测量。
