# FlashInfer NAR kernel screening — 2026-10-10

目标：核查当前 H800 上 FlashInfer 是否能改善已定位的 NAR 算子热点。当前零拷贝候选及公共执行源码保持不变；所有替换仅在外置实验进程内发生。无依赖安装、精度修改、权重/音频/latent 保存。

## 方法

SSH36665，FlashInfer 0.7.0.post1，现有 torch/vLLM/CUDA 环境，MPS off、OMP/MKL1、原功率时钟。固定 seed 20261010、BF16，NAR 真实形状：B1 1024/6144 帧，B2 4096+4096/6144+1024，B4 1024×4。前缀2529；Q=帧+2，K=2529+2×帧+3，Q/KV heads=16/8、head_dim128。

算子筛选使用合成固定输入，3次预热后CUDA Graph捕获，五轮轮换 backend 顺序、每轮32 replay，以CUDA event中位数计时，最终attention workspace均256MiB。它不含模型权重、plan/JIT/Graph构建成本，不是完整NAR或E2E。GEMM用torch.mm/addmm作形状代理，不能代替生产编译子图验收。SiLU参考表达式按生产compile options编译。

Attention比较当前vLLM FA3与FlashInfer ragged wrapper FA3/FA2/cuDNN；plan在计时外，非因果、无新RoPE。cuDNN的indptr使用元素单位及显式seq lengths，其余backend为token单位。GEMM仅测本机可用的cuDNN/cuBLASLt BF16路径；未测试SM100专用路径、FP8/FP4、cuTile或PDL。

完整NAR对照复用此前真实模型/fixture/生产CachedNAR、BatchedCachedNAR及Graph pool。仅外置替换 `_nar_post_attention` 中SiLU×gate为FlashInfer；保留两侧norm/投影/residual的torch.compile及原FA3、ODE、packed KV。每种形状按 current→FlashInfer→FlashInfer→current 顺序，各臂3次velocity预热、1次完整ODE预热、2次完整ODE计时。比较完整velocity及latent，检查重复精确和有限值。没有AR/VAE共跑，不生成音频；frames/s不是内容TPS，不能直接推出E2EL/RTF/音频吞吐。

## 运行记录

首轮筛选完成但部分backend未覆盖：cuBLASLt缺少链接名，cuDNN调用传入了token offsets。原始日志/结果/脚本保留于evidence/first-pass，不作为最终数据。只在实验lib目录为环境已有cuBLAS库增加链接名并设置LIBRARY_PATH，未修改安装包；cuDNN指定已有libcudart.so.13。外置脚本补充初始stream依赖，修正cuDNN参数后重新筛选。

第二轮B2等长FA2 plan的128MiB workspace不足，明确失败并保留整轮证据于evidence/second-pass。最终统一使用256MiB workspace重跑所有算子；不把内存不足记为FA2性能结果。

完整NAR前两次运行直接调用FlashInfer Python wrapper均触发fullgraph编译错误（惰性JIT的文件操作；预初始化仍未绕过）。随后试验torch.ops入口发现本机FlashInfer的register_custom_op/register_fake_op实现为no-op，没有实际注册；该smoke错误同样保留。最终外置fi_op.py使用torch.library.custom_op及fake shape包住同一FlashInfer kernel，完整post子图compile smoke输出精确。没有修改安装包或生产源码，也没有通过关fullgraph/退回eager规避错误。

完整NAR结果见文末。

API参考：[FlashInfer BF16 GEMM](https://docs.flashinfer.ai/generated/flashinfer.gemm.mm_bf16.html)、[FlashInfer attention](https://docs.flashinfer.ai/api/attention.html)。实际支持及参数以本机0.7.0.post1源码核对；FlashInfer wrapper本身不保证比现有FA3快。

结论：本机实测支持继续采用FlashInfer SiLU×gate作为小范围候选，保留当前FA3及GEMM。两种SiLU实现本来都已融合，不能把收益归因于“首次融合”，也没有NCU证据定责访存/向量化。单算子倍率不是完整NAR倍率。此次没有更换当前候选或默认设置。

筛选温度35–48°C，完整NAR36–67°C，均无thermal slowdown采样；未锁频，设备日志含初始化/空闲段。两项运行allocator retry/OOM均0，完整NAR最终状态空。1860生产文件本地/远端/运行前后一致。完整NAR RPC嵌套complete及case数量已校验，失败RPC不当作成功。

未测新E2EL、内容TPS、音频吞吐、RTF、部署显存上限、VAE音频、WSB/听感、其它GPU或CFG≠1；不把固定输入latent精确外推为这些验收。未commit/push，无模型或生成产物下载。
