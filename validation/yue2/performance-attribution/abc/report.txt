# Automatic ABC: projection work and acoustic supply

## Setup

H800, 2026-10-08; base `c548a110` plus shared loading fix `631f5573`. Compare automatic ABC, two-call PR and two-call main, in that order, using 64 matched prompts/seeds and two full warmups per process. AR32/KV32 GiB/client 64, full CoT/CFG1, ABC 4096/semantic 9000; PR NAR1/VAE1/window 0. Both PR runs include the output-ownership fix. Measurements include external observation wrappers.

## Results

| Metric | main two-call | PR two-call | PR automatic ABC |
| --- | ---: | ---: | ---: |
| Audio seconds / wall second | 17.589 | 18.121 | 17.870 |
| Relative to main | — | +3.02% | +1.60% |
| E2EL P50/P95 (s) | 449.47/745.82 | 439.09/735.18 | 428.05/749.17 |
| RTF P50/P95 | 2.028/3.103 | 2.011/2.928 | 1.770/2.991 |
| Sampled device peak (GiB) | 65.91 | 59.90 | 65.66 |

Automatic ABC increased projected elements by 37.94% and reduced throughput by 1.38% versus the same-source two-call path. Mixed ABC/semantic calls were 41.93% versus 16.89%; semantic rows in mixed calls were 54.29% versus 20.58%. Full-vocabulary projection is used whenever ABC is present; semantic sampling remains restricted.

The ABC handler took 3.357 s over 130448 calls, 0.415% of host wall time. Acoustic gaps were 94.67/54.71/64.32 s for automatic/two-call/main, almost entirely with no ready job; ready-but-not-started time was about 1 ms per run. VAE structure was unchanged; the historical standard VAE and this legacy VAE differ in weights, not an identified extra execution branch.

## Scope

One sequential, instrumented comparison under thermal throttling: median SM 810 MHz, with approximately 90–92% of samples throttled. Projection-element counts measure projection work; output lengths and truncations also differ. The historical 3090 queue experiment used a different device, load and revision.
