# Pre-capture cache preparation: single-variable diagnosis

## Setup

2026-10-13. An isolated copy adds only device synchronization and empty_cache before side-stream capture_begin. Same failing 32 prompt/seed load, two full warmups; AR1/KV3 GiB/client 2/NAR1/VAE1/window 0/token-budget 0/fullCoT/CFG1. ## Results

All 32/32 measured requests and 2/2 warmups completed; zero allocator retries/OOM. The formerly failing request returned fully, and all 17 requests shared with the failed run matched ABC hashes, semantic hashes and frame counts. The retained-change summary records reserved memory at that capture falling 19.633→13.502 GiB.
