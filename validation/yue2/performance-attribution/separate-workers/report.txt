# Single worker versus KV-transfer split: architecture probe

## Setup

2026-10-03, same RTX 3090, torch 2.13/cu130, vLLM 0.30, transformers 5.14. `631f5573` plus the frozen two-stage experiment. AR4/KV4 GiB/context 24576, receiver capacity 4/acoustic execution 1, on-demand allocation. Same prompts/seeds and 512/768/1024/1280 frame budgets. Clean timing uses production workers; a separate observed pair records stages and IPC.

## Results

| Clean timing | Single worker | Two workers |
| --- | ---: | ---: |
| One 1024 frame request | 11.029 s | 10.694 s |
| Concurrent 4 median(three rounds) | 23.199 s | 24.756 s |
| Audio/s | 6.179 | 5.791 |

Concurrent throughput fell 6.29%; the single-request 3.04% reduction is one trial. Probe HOLD rows fell 698→0 (233 HOLD-only steps removed). AR backbone kernel union fell 11.684→10.156 s, but NAR union rose 16.098→19.425 s. All eager/capture/replay counts remained 4/4/248.

Four publishes totaled 264.710 ms; final ACK waits 251.769 ms. Gather kernels totaled 3.049 ms, while IPC close calls totaled 171.646 ms. Receiver slots never filled. GPU IPC still gathers into contiguous KV, so this is not end-to-end zero-copy; conditioning prefill remains.

Parameter storage 6.916191→6.916194 GiB differs only by 4096 B final norm. Device trace peaks 19303→20368 MiB; extra memory is not all live KV. Last semantic completion moved about 17.21→15.79 s, while acoustic work queued afterward.

## Scope

Three requests produced different semantic tokens despite fixed frame counts. Kernel/event spans include contention and overlap. Co-running acoustics and synchronous handoff remain the leading explanations; context switching and stream priority were not isolated. In-flight cancellation/shutdown remained untested.
