# Batch wait window, pinned-view fix and E2E controls

## Setup

2026-10-08, thermally limited H800 PCIe 80 GB/595.71.05, torch 2.13.0+cu130/vLLM 0.31.0, OMP/MKL 1. Base `c548a110a5a9bc278c39cfa81e673a8d505a24dd` plus shared loading fix `631f5573`. Adds finite nonnegative ready-time-based wait deadline (default 0; B1 never waits) and a contiguous view into the existing sampler pinned buffer. NAR/VAE arithmetic unchanged.32 song calibrations precede 64 song formal runs.

## Results

| AR/KV GiB/window ms | Audio/s | E2EL P95 (s) | Device peak (GiB) | Songs in B2 jobs |
| --- | ---: | ---: | ---: | ---: |
| 16/16/200 | 15.739 | 427.00 | 45.91 | 6/32 |
| 16/32/0 | 16.075 | 414.40 | 60.56 | 6/32 |
| 16/32/1000 | 16.067 | 419.61 | 67.06 | 10/32 |
| 16/32/200 | 16.060 | 414.67 | 60.56 | 6/32 |
| 32/32/200 | 17.794 | 372.08 | 73.58 | 18/32 |

The 200 ms window did not increase B2 coverage;1000 ms increased coverage but not throughput. Formal PR→main→main→PR used AR32/KV32 GiB/client 64, fullCoT/CFG1, ABC 4096/semantic 9000, PR NAR2/VAE1/window 200 ms, two full warmups each, no batch/step probes.

Paired audio-throughput changes were +1.57%/+0.81%; E2EL P95+0.46%/−0.19%, RTF P95−4.24%/+1.17%; device peaks increased 12.25/12.21 GiB. PR peaks 76.46 GiB versus main 64.21/64.24 GiB. Audio-duration changes +0.080%/−0.889% and all truncations were retained.

46 CPU checks passed;160 calibration/256 formal outputs plus 10/eight warmups passed. Approximately 92% of formal samples thermally throttled, median SM795/780 MHz for PR and 780 MHz for main. Two later B1 attempts failed; the separate output-handoff repair subsequently passed 128 full requests.

## Scope

One calibration run per setting, followed by formal runs under severe thermal throttling. Formal recipes combine waiting, pinned views and other changes. The high-throughput recipe left about 3.19 GiB; longer loads need a separate capacity check.
