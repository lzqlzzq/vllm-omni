# Unifying the existing YuE2 entry point

## Setup

Historical functional acceptance on 2026-10-12 against `c548a110`, before the later upstream migration. Keep one `yue2` pipeline, `Yue2ForCausalLM`, `yue2.yaml` and `/v1/audio/speech` adapter. Preserve supplied ABC/two-call clients; add automatic ABC, paired CFG and configurable NAR batching. At this revision the runtime module was named `queued.py`; it was renamed later.

## Results

Automatic ABC uses independent stage presets/seed reset. CFG=1 follows native AR admission without whole-output KV reservation; CFG pairs reuse atomic shared scheduling and reserve their actual prefix/output capacity. Invalid-capacity pairs fail per-request and leave the engine reusable. The public engine companion gate is unchanged.

Defaults retained context 24576/AR4/utilization 0.70/eager backbone, with synchronous FCFS/v 1 worker and NAR1/VAE1/window 0/budget 0. Default token budget 4297→202 removes acoustic HOLD allowance. APC/external KV/speculation/TP>1/PP>1 are rejected; ordinary chunked prefill is configurable, CFG requires full prefill.

205 CPU tests passed (21 warnings), plus applicable hooks. On RTX 4090, AR1 produced four valid outputs and rejected one oversized CFG pair; AR2 produced six, including mixed automaticABC/CFG, with 402 shared-token sampling steps. Five HTTP cases returned valid 48 kHz stereo WAV; CFG21 and ABCbudget 0 returned 400. Final states/active/waiting were empty.

## Scope

GPU checks used context 4096/KV3 GiB, 200 audio frames and ABC budget 32. They cover short functional behavior; packed B2 and in-flight shutdown were untested. Capture preparation, the later `f9143976` migration and ABBA have separate records.
